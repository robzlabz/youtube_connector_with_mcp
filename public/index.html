Connect to YouTube

Authorize this app with your Google account. Google redirects back to http://localhost:3000/oauth2callback, the app stores the token locally and shows it to you.

  • Credentials are read from .env (Google Cloud Console → OAuth client).
  • You grant the youtube scope (upload + manage).
  • Tokens are written to data/tokens.json (mode 600), one entry per channel.
  • Connect as many channels as you want — each consent adds one account.
  • Already have a token from another machine? Paste it in Import / export token.

YouTube account

Token

Use it from anywhere: Authorization: Bearer <access token>. Example: curl -H "Authorization: Bearer $TOKEN" "https://www.googleapis.com/youtube/v3/channels?part=snippet&mine=true"

Import / export token

Copy a token here and paste it on another machine (local ↔ server) to connect the same account without repeating the OAuth flow. The JSON holds access_token + refresh_token — treat it as a secret.
